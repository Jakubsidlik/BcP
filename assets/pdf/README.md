# Kam nahrat PDF soubory

Do teto slozky nahrajte oba PDF soubory:

1. `bakalarska-prace.pdf`
2. `print-play.pdf`

Pouziji se takto:

- `index.html` nacita a stahuje `assets/pdf/bakalarska-prace.pdf`
- `print-play.html` nacita a stahuje `assets/pdf/print-play.pdf`

Nazvy souboru ponechte presne, aby odkazy fungovaly bez dalsich uprav.
